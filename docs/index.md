# AI for Detector Operations

Cross-experimental AI for operations at [Argonne National Laboratory](https://www.anl.gov/). This project applies machine learning to operational time-series data from large-scale physics and astrophysics experiments, with the goals of **real-time hardware fault detection** and **model-agnostic new-physics searches**. A single shared framework (`anldq`) runs the same anomaly-detection pipeline across every supported detector.
